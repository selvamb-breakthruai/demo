# CRUD Demo

Simple CRUD application using:
- Frontend: HTML, CSS, JavaScript
- Backend: Express.js
- Database: SQLite

## Run

1. Open a terminal in the project folder
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000`

## API

- GET `/api/items`
- POST `/api/items` with `{ title, description }`
- PUT `/api/items/:id` with `{ title, description }`
- DELETE `/api/items/:id`
